# 전설 — 관절과 겹침 수정본

기준은 두 번째 수정 후 처음 업로드한 `844e7c2`입니다. [비교 화면](index.html)에서 기준 그림, 닫힘, 펼침, 실제 재생을 함께 볼 수 있습니다. 97번을 가장 먼저 배치했습니다.

## 달라진 조립 구조

97번은 완전한 날개 몸체와 독립 깃털 묶음을 겹쳐 구성했습니다. 어깨 → 중간 관절 → 깃털의 상하 관계를 두고, 어깨 연결점은 고정한 채 깃털 각도가 서로 다르게 변합니다. 오른쪽 날개는 같은 구조를 대칭으로 사용합니다. 테두리는 움직이지 않습니다.

나머지 전설도 첫 업로드의 얇은 테두리와 장식 배치에 맞춰 고정 지지부를 다시 그렸습니다. 기어는 중심축으로 회전하고, 가지는 줄기 뿌리에서 흔들리며, 수정은 부유·벌어짐, 별은 호흡, 용은 작은 끄덕임을 적용했습니다. 장식을 테두리의 부채꼴 조각으로 추출하지 않습니다.

## 파일

- `profile_NNN_legendary.svg`: 실제 사이트 재생용. PNG 그림과 효과를 모두 포함합니다.
- `profile_NNN_closed.png`, `profile_NNN_open.png`: 실제 브라우저에서 캡처한 닫힘·펼침 비교.
- `layers/NNN/`: 전설별 완전한 고정 테두리와 독립 장식 PNG.
- `097-frame.png`, `097-upper-body.png`, `097-*-feathers-*.png`: 97번 전용 테두리·날개 몸체·깃털 묶음.
- `097-rig.json`, `manifest.json`: 연결점, 배치, 관절 각도와 구성 정보.
- `sources/`: 고정 테두리와 깃털을 별도로 그린 원화.

전체 1024×1024px, 중심 (512,512), 안쪽 원 지름 716px, 중앙 완전 투명입니다. 후광·명암 이펙트와 동작 줄이기 설정을 지원합니다. ZIP 없이 개별 PNG·SVG로 저장했습니다.

## 재조립·확인

```sh
python3 tools/build_articulated_097.py
python3 tools/build_articulated_legendary.py
python3 tools/validate_articulated_legendary.py
python3 tools/preview_articulated_legendary.py
```

검증은 10종×5시점에서 고정 테두리, 안쪽 원, 중앙 투명도, 동작 줄이기를 확인합니다. 97번은 어깨 연결점 고정과 중간 관절의 상위 팔 연결도 검사합니다. `validation.json`은 이 기술 검증 결과이며, 그림과 동작의 모습은 비교 화면의 닫힘·펼침·재생으로 확인할 수 있습니다.

일반·고급·희귀·영웅과 이전 전설 폴더는 보존했습니다.
