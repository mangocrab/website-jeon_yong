# 전설 — 독립 장식 원화로 조립한 동작

기준 디자인은 두 번째 수정 후 처음 GitHub에 업로드한 `844e7c2`입니다. 전설 10종의 원래 색과 주요 장식에 맞춰, 완전한 테두리와 끝선·연결 뿌리를 갖춘 장식을 각각 그렸습니다.

[동작과 독립 장식 보기](index.html)

- `profile_NNN_legendary.svg`: 사이트에서 img로 사용하는 애니메이션.
- `profile_NNN_legendary.png`: 새 레이어를 조립한 정지 그림.
- `layers/NNN/frame.png`: 장식 뒤쪽까지 이어 그린 완전한 테두리.
- `layers/NNN/ornament-N.png`: 투명 여백을 가진 완전한 독립 장식 그림.
- `sources/NNN.png`: 테두리와 독립 장식을 따로 그린 원화 시트.
- `manifest.json`: 장식 위치·크기·회전축.

날개와 가지는 뿌리를 중심으로 펼쳐지거나 흔들리고, 기어는 기어 중심축으로 회전합니다. 테두리는 고정합니다. 움직이는 부품에 원형 띠나 부채꼴 절단 마스크를 사용하지 않습니다.

1024×1024px, 중심 (512,512), 안쪽 원 지름 716px이며 중앙은 투명합니다. 후광·명암 효과를 포함합니다. 운영체제의 동작 줄이기 설정을 따릅니다.

검증에서는 테두리와 이펙트를 숨기고 전체 보호 마스크까지 해제한 상태로 장식만 렌더링합니다. 10종×5개 시점에서 장식이 중앙 원이나 화면 가장자리에 닿아 잘리는 픽셀이 0인지 검사합니다. 결과는 `validation.json`에 있습니다.

```sh
python3 tools/build_independent_legendary.py
python3 tools/validate_independent_legendary.py
```

이전 파일은 보존했습니다. 영웅과 다른 등급의 파일은 이번 수정 대상에 포함하지 않았습니다. ZIP 없이 개별 파일로 저장합니다.
